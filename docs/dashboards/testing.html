Testing & Validation

Test strategy & CI quality gate

Fast, database-free unit tests guard the security-critical query gateway and run everywhere. Integration and provider tests need live infrastructure and run locally or against a CI service container. Every push is gated by lint, type-check and the test suite.

3 · What the safety-net suite locks down

These assertions protect the Phase 3 driver migration (%s → ? placeholder change).

GuaranteeWhy it mattersTests
Read-only mode blocks writesINSERT/UPDATE/DELETE/DROP rejected with PermissionError4
SQL-comment bypass blocked-- and /* */ cannot smuggle writes past the prefix check2
Parameters forwarded unchangedCatches a broken placeholder rewrite during driver migration1
Allowed read prefixes passSELECT / SHOW / DESC / USE reach execution1
Result limitingRespects MCP_MAX_RESULTS; honours limit_results=False2
Pool / DB-switch behaviourMissing pool raises; USE `db` issued first2

4 · Run it yourself

Database-free unit tests (fast, no setup):

uv run pytest src/tests/test_execute_query_unit.py src/tests/test_list_databases_unittest.py -v

Full suite (requires live MariaDB with configured .env):

uv run pytest src/tests/ -v
