Deployment topology & data sources

The server ships as a Docker Compose stack for local use and connects to several internal MariaDB servers in operation. One key downstream dataset, kbme_statistic, is refreshed daily from raw KBE logs joined with Active-Directory user snapshots.

3 · kbme_statistic data pipeline

Raw logs + AD snapshots are consolidated into reporting tables. Data is current, but the DB event scheduler is DISABLED — an external job drives the refresh.

  classDef off fill:#2a1518,stroke:#f85149,color:#e6edf3;

  class O1,O2 live;

If the daily refresh ever stalls, check the external scheduler and the general query log on edecdems015 for CALL kbme_statistic.UpdateKBMELogs — the DB events have not run since July 2024 even though the data keeps growing.
